# 三传感器 NOx 控制策略与自动读数检测设计

本文档基于现有双传感器代码进行设计说明，**不修改任何代码**，仅作为扩展为三路传感器时的策略与“读数一致性检测”方案参考。

---

## 一、现有代码要点回顾

### 1.1 通道与数据

- **通道数**：当前 `NOX_SENSOR_COUNT = 2`，`NOX_SENSOR_COUNT_MAX = 3`，已为三路预留。
- **每通道数据**：`raw_nox/raw_o2` → 标定后 `nox_ppm`、`o2_pct`，以及 9 位 `state`、`valid = (state == 0x1FF)`。
- **J1939 源地址**：当前为 `[0x52, 0x51]`（出口/入口），第三路需新增一个 SA（如 0x50）。

### 1.2 工作模式（P34 低字节）

| 模式 | 值 | 含义 |
|------|---|------|
| SINGLE | 0 | 仅指定单通道输出；吹扫时切到非吹扫通道；指定通道无效时可切到另一有效通道。 |
| PRIMARY_BACKUP | 1 | 主备：吹扫优先用非吹扫通道，否则按 ch0→ch1 选第一个有效通道。 |
| FUSION | 2 | 融合：仅在**双通道都有效且都未吹扫**时取平均；否则退化为主备。 |

### 1.3 输出与回读

- 当前输出：单一 4–20 mA（NOx/O2）由策略选出的 `nox_ppm`、`o2_pct`、`state` 驱动。
- P34 高字节回读：0=S1，1=S2，2=融合，0xFF=故障（无有效路径）。

## 二、三传感器时的控制策略扩展

### 2.1 工作模式扩展（概念）

- **SINGLE（0）**  
  - 单通道索引扩展为 0/1/2（P34 高字节或新约定：0=S1，1=S2，2=S3）。  
  - 逻辑与现有一致：选定通道吹扫 → 用其他非吹扫通道；选定无效 → 按优先级（如 0→1→2）选第一个有效非吹扫通道；全无效 → 故障回读 0xFF。

- **PRIMARY_BACKUP（1）**  
  - 优先级顺序固定为 ch0 → ch1 → ch2。  
  - 吹扫：任一通道吹扫时，输出从**未吹扫**且**有效**的通道中按优先级选取。  
  - 无有效非吹扫通道时，可再按优先级用“任意有效”通道；若全无效则故障。

- **FUSION（2）**  
  - **三路融合**：仅当 ch0、ch1、ch2 **都有效**且**都未吹扫**时，对 NOx、O2 做**三路平均**（或加权平均/中值，见下）。  
  - 若仅两路有效且未吹扫，可做**两路平均**，并视需求决定是否标记“降级融合”。  
  - 若仅一路有效或全吹扫，退化为单路输出（等价于主备只选到一条路径）。

### 2.2 三路融合的两种输出方式（建议）

- **均值**：  
  `nox_out = (n0 + n1 + n2) / 3`，O2 同理。  
  实现简单，与当前双路融合一致；对单路野值较敏感。

- **中值（推荐用于抗野值）**：  
  `nox_out = median(n0, n1, n2)`，O2 同理。  
  在“两正一偏”时自动屏蔽偏离的那一路，无需额外一致性判断即可部分实现“自动读数检测”效果（见第三节）。

## 三、三传感器自动读数检测（一致性/偏离判断）

目标：**当某一传感器读数明显偏离另外两个时，判定该传感器读数不可信**，可用于屏蔽该路参与融合或标记故障。

### 3.1 思路概述

- 三个数中，若**两个接近、一个明显偏离**，则偏离的那个可视为“异常”。  
- 可用于：  
  - 融合时**排除**该路（只对“一致的两路”取平均或直接用中值）；  
  - 或仅**标记**该路为“一致性无效”，供主备/单通道策略降权或告警。

### 3.2 方法一：阈值法（成对偏差）

对 NOx（ppm）和 O2（%）分别做：

- 设三路值为 \(v_0, v_1, v_2\)。
- 计算两两差的绝对值：  
  \(d_{01}=|v_0-v_1|,\ d_{02}=|v_0-v_2|,\ d_{12}=|v_1-v_2|\)。
- 若**存在一对** \((i,j)\) 使 \(d_{ij} \le \varepsilon\)（认为 i、j 一致），且**第三路** k 对 i、j 都偏差大：  
  \(\max(d_{ki}, d_{kj}) > \Delta\)（\(\Delta > \varepsilon\)），则判定 k 为偏离路。

**参数建议**（需现场标定）：

- NOx：\(\varepsilon\) 如 30–50 ppm，\(\Delta\) 如 80–150 ppm（或按满量程百分比）。  
- O2：\(\varepsilon\) 如 0.5%，\(\Delta\) 如 1.0–1.5%。

**判定结果**：  
- 若某路被标为“偏离”，则该路在本周期内不参与融合（或仅作备用），并可把该路 `state` 的某一位或 Modbus 中“一致性无效”置位，便于上位机/运维查看。

### 3.3 方法二：中值偏差法

- 先算中值：\(m = \mathrm{median}(v_0, v_1, v_2)\)。  
- 若某路 \(v_k\) 满足 \(|v_k - m| > \Delta\)，则判定 k 为偏离路。  
- \(\Delta\) 可与上面一致（NOx/O2 分别设），或按量程百分比。

优点：实现简单，与“融合用中值”自然配合；缺点：当三路都偏时无法区分“哪个坏”（此时只能依赖 J1939 的 FMI/state）。

### 3.4 方法三：2-out-of-3 投票（一致对）

- 若 \(d_{01} \le \varepsilon\) 且 \(d_{02} > \Delta\) 且 \(d_{12} > \Delta\) → 0、1 一致，2 偏离。  
- 若 \(d_{02} \le \varepsilon\) 且 \(d_{01} > \Delta\) 且 \(d_{12} > \Delta\) → 0、2 一致，1 偏离。  
- 若 \(d_{12} \le \varepsilon\) 且 \(d_{01} > \Delta\) 且 \(d_{02} > \Delta\) → 1、2 一致，0 偏离。  
- 若三路两两都接近（如都 \(\le \varepsilon\)）→ 无偏离，三路都参与。  
- 若三路两两都差很多 → 无法形成“一致对”，可认为**无可靠输出**（三路都标为不可信或保持上一周期输出）。

逻辑上与“方法一”等价，只是表述成“投票”形式，便于和 2-out-of-3 安全规范对应。

### 3.5 与现有 valid 的结合

- 当前 `valid` 仅表示 J1939 状态字/FMI 正常（state==0x1FF）。  
- 建议增加“**一致性有效**”概念（可仅在策略内部使用，或写回寄存器）：  
  - **逻辑有效** = J1939 valid **且** 未在一致性检测中被判为“偏离”。  
- 融合时：  
  - 仅对“逻辑有效”的通道做平均或中值；  
  - 若仅剩一路逻辑有效，则退化为单路输出；若全无效则故障（0xFF）。

这样既保留现有“传感器自身报错”的判断，又增加“三个之间互相校验”的能力。

### 3.6 小结：三路是否可以自动判断“读数不对”

- **可以**。利用“两路接近、一路偏离”的几何关系，用阈值法或中值偏差法即可判断“哪一路读数不对”。  
- 建议：  
  - **融合输出**优先用**中值**，自然抑制单路野值。  
  - **显式一致性检测**用阈值法或 2-out-of-3 投票，得到“偏离路”并屏蔽该路参与融合或打“一致性无效”标记。  
  - 参数 \(\varepsilon\)、\(\Delta\) 需根据实际工况（量程、噪声、安装位置）标定，并可做成可配置（如通过 Modbus 或 Flash）。

## 四、吹扫（Blowback）与三通道

- 现有逻辑：某通道吹扫时，该路气体被 purge，输出必须来自**其他未吹扫**通道。  
- 三路时：  
  - 任一路吹扫 → 从**未吹扫**且**有效**的通道中按主备优先级或融合规则选/平均。  
  - 当前实现采用**共享吹扫周期 + 三等分相位**：上电后 S2/S3 分别在 1/3、2/3 周期相位触发，S1 在第 1 个完整周期触发，避免两路同时吹扫导致只剩一路可用。

## 五、寄存器与回读扩展（设计建议，不涉及改代码）

- **S3 块**：与 S1、S2 同构，增加 live_nox、live_o2、status、标定、吹扫间隔/时长等。  
- **P34**：  
  - 低字节：工作模式 0/1/2 不变。  
  - 高字节：单通道时 0/1/**2**（S1/S2/S3）；回读时 0/1/2/3（3 表示三路融合）及 0xFF（故障）。  
- **一致性状态**（可选）：每个通道增加“一致性无效”位或单独寄存器，便于上位机显示“该路被判定为偏离”。

## 六、总结

| 项目 | 说明 |
|------|------|
| 三路工作模式 | SINGLE(0/1/2)、PRIMARY_BACKUP(0→1→2)、FUSION(三路均有效且未吹扫时取平均或中值)。 |
| 自动读数检测 | 可以：通过“两路接近、一路偏离”做阈值法或中值偏差法，判定偏离路并屏蔽或标记。 |
| 融合抗野值 | 建议三路融合时用**中值**输出，或对“一致性有效”通道做平均。 |
| 与现有代码关系 | 上述均为设计说明，不要求在本文档中修改任何现有代码；实现时需改 `NOX_SENSOR_COUNT`、SA 列表、策略分支和寄存器/OLED 等。 |

以上设计可直接作为“增加一个传感器”后的控制策略与自动读数检测的落地依据，后续实现时再按需在 `nox_channel.c`、`NOx.c`、Modbus 与配置中具体编码。
