# NOxDebug 使用手册

本文档面向现场调试、上位机配置、标定和维护人员，说明当前固件如何接线、如何读数、如何切换工作模式、如何控制阀门、如何执行手动标定，以及遇到异常时如何判断问题。

当前固件为三传感器版本：

- S1 / ch0：片载 CAN1，J1939 源地址 0x52。
- S2 / ch1：片载 CAN1，J1939 源地址 0x51。
- S3 / ch2：MCP2515 第二路 CAN，J1939 源地址 0x52。

S1 和 S3 都使用 0x52，但在两条物理 CAN 总线上，软件按接收来源区分，不冲突。

---

## 1. 快速上手

### 1.1 上电后先看什么

建议按下面顺序确认系统状态：

1. 读 40013，确认当前输出来源。
2. 读 40005，确认当前输出状态字。
3. 读 40015-40019、40057-40061、40099-40103，确认 S1/S2/S3 各自读数和状态。
4. 读 40050/40092/40134，确认是否有通道正在反吹。
5. 读 40053-40055、40095-40097、40137-40139，确认阀门实际寄存器状态。
6. 读 40014/40056/40098，确认 JC1/JC2/JC3 传感器使能状态。

### 1.2 常用寄存器速查

| 功能 | S1 | S2 | S3 | 说明 |
|------|----|----|----|------|
| 传感器使能 | 40014 | 40056 | 40098 | 1=使能，0=关闭；驱动 JC1/JC2/JC3 |
| 实时 NOx | 40015-40016 | 40057-40058 | 40099-40100 | float |
| 实时 O2 | 40017-40018 | 40059-40060 | 40101-40102 | float |
| 状态字 | 40019 | 40061 | 40103 | 0x1FF=正常；0x0300 常见于未收帧/通信超时 |
| 反吹状态 | 40050 | 40092 | 40134 | 0=空闲，1=反吹中 |
| 反吹倒计时 | 40051 | 40093 | 40135 | 秒；手动直接开反吹阀时为 0 |
| 反吹命令 | 40052 | 40094 | 40136 | 1=触发一次，2=触发并重置周期，3/0xFFFF=停止 |
| 正常抽气阀 | 40053 | 40095 | 40137 | J1/J4/J7 |
| 反吹阀 | 40054 | 40096 | 40138 | J2/J5/J8 |
| 校准阀 | 40055 | 40097 | 40139 | J3/J6/J9 |

公共寄存器：

| 地址 | 名称 | 说明 |
|------|------|------|
| 40001-40002 | P01 | 当前策略输出 NOx，float |
| 40003-40004 | P02 | 当前策略输出 O2，float |
| 40005 | P07 | 当前策略输出状态字 |
| 40006-40007 | P12 | NOx 高报警阈值，float |
| 40008-40009 | P13 | O2 低报警阈值，float |
| 40010 | P22 | 当前策略输出 NOx 的 4-20 mA 内部码 |
| 40011 | P23 | 当前策略输出 O2 的 4-20 mA 内部码 |
| 40012 | P34 | 工作模式 |
| 40013 | P35 | 当前实际输出来源 |

## 2. 硬件对应关系

### 2.1 传感器使能继电器

当前版本已启用传感器使能 GPIO，`SENSOR_POWER_GPIO_ENABLE=1`。

| 传感器 | 使能寄存器 | 继电器 | MCU 引脚 | 默认上电状态 |
|--------|------------|--------|----------|--------------|
| S1/ch0 | 40014 | JC1 | PC0 | 1 |
| S2/ch1 | 40056 | JC2 | PC13 | 1 |
| S3/ch2 | 40098 | JC3 | PB9 | 1 |

写对应寄存器为 1 时输出高电平，写 0 时输出低电平。当前按高电平有效处理；如果硬件为低电平有效，需要在 GPIO 写入层取反。

### 2.2 阀门继电器

| 传感器 | 正常抽气 | 反吹 | 校准 |
|--------|----------|------|------|
| S1 | J1 / PA4 / 40053 | J2 / PA3 / 40054 | J3 / PA1 / 40055 |
| S2 | J4 / PA0 / 40095 | J5 / PC3 / 40096 | J6 / PB3 / 40097 |
| S3 | J7 / PB4 / 40137 | J8 / PB5 / 40138 | J9 / PB8 / 40139 |

阀门寄存器统一为 0=关，1=开。

当前阀门互锁规则：

- 打开正常抽气阀时，同路反吹阀会自动关闭。
- 打开反吹阀时，同路正常抽气阀会自动关闭。
- 打开校准阀时，同路正常抽气阀和反吹阀都会自动关闭。
- 校准阀保持打开期间，再写正常抽气阀或反吹阀为 1，也会被保持关闭。
- 同路非反吹、非校准时，手动写正常抽气阀为 1 会进入手动抽气覆盖，可在传感器尚未达到 `0x1FF` 时打开抽气阀。
- 手动写正常抽气阀为 0 会关闭抽气阀并退出手动抽气覆盖。
- 手动直接打开反吹阀时，系统会把该路视为正在反吹，输出策略会避开该路，自动抽气也不会再打开该路抽气阀。

## 3. 工作模式

工作模式由 40012/P34 控制。读 40012 时只读回低字节模式，不读回高字节通道选择。要判断当前实际输出来自哪里，必须读 40013/P35。

### 3.1 P34 写入编码

| 写入值 | 模式 | 含义 |
--------|------|------|
| 0 | 单路 | 目标 S1/ch0 |
| 256 | 单路 | 目标 S2/ch1 |
| 512 | 单路 | 目标 S3/ch2 |
| 1 | 主备 | S1/ch0 为主 |
| 257 | 主备 | S2/ch1 为主 |
| 513 | 主备 | S3/ch2 为主 |
| 2 | 融合 | 至少两路有效且不在反吹/恢复保持期时平均 |

上电默认是 1，即主备模式，S1/ch0 为主。

### 3.2 P35 输出来源

| 40013 值 | 含义 |
----------|------|
| 0 | 故障，无有效输出源 |
| 1 | S1/ch0 |
| 2 | S2/ch1 |
| 3 | 融合输出 |
| 4 | S3/ch2 |

### 3.3 单路模式行为

单路模式不是绝对锁死某一路，而是“目标通道优先”：

- 目标通道正常有效且不在反吹/恢复保持期时，输出目标通道。
- 目标通道正在反吹或处于恢复保持期时，临时切到其它已稳定且有效通道。
- 目标通道无效时，也会尝试切到其它已稳定且有效通道。
- 如果没有任何可用通道，则 P35=0，P01/P02 维持目标通道缓存值，P07 使用目标通道状态。

这里的“故障回退”不是停机，而是标记 P35=0，同时维持最后缓存输出，避免输出链路突然空掉。

### 3.4 主备模式行为

主备模式按 P34 高字节选择主通道。主通道有效且不在反吹/恢复保持期时使用主通道；否则寻找其它已稳定且有效通道。全部无效时 P35=0，输出主通道缓存值和状态。

### 3.5 融合模式行为

融合模式当前实现为：至少两路有效且不在反吹/恢复保持期时，对这些通道做算术平均。不是必须三路全有效。

- 两路有效：两路平均，P35=3。
- 三路有效：三路平均，P35=3。
- 只有一路有效：降级为主备选择。
- 全部无效：P35=0。

当前没有实现中值融合、偏离通道自动屏蔽或 2-out-of-3 一致性投票。

## 4. 状态字

P07 和各传感器状态寄存器使用同一类状态字。`0x1FF` 表示该路由 J1939 推导出的传感器状态全部正常，且没有固件通信超时。

| 位 | 置位含义 |
----|----------|
| bit0 | O2 FMI 正常 |
| bit1 | NOx FMI 正常 |
| bit2 | 加热 FMI 正常 |
| bit3 | 加热激活 |
| bit4 | 电源在范围 |
| bit5 | 传感器达温 |
| bit6 | O2 信号有效 |
| bit7 | NOx 信号有效 |
| bit8 | 固件保留，恒置位 |
| bit9 | 固件通信超时/链路丢失 |

常见状态：

- `0x1FF`：正常。
- `0x0300`：bit8 + bit9，通常表示上电后未收到该路 CAN 帧，或超过 2000 ms 没收到该路 CAN 帧。
- 非 `0x1FF` 且 bit9 未置位：收到了 CAN 帧，但传感器状态、稳定性、温度、供电或 FMI 有条件未满足。

## 5. 反吹操作

### 5.1 自动周期反吹

三路共享一个反吹周期，默认周期 3600 s，默认时长 60 s。三路按三等分相位错开：

- S2 在 1/3 周期相位触发。
- S3 在 2/3 周期相位触发。
- S1 在第一个完整周期触发。

通过自动周期或 `BLOW_CMD` 启动反吹时，同一时刻只允许一路反吹。

反吹周期写 0 或 0xFFFF 时，只停止自动周期反吹；仍允许通过 `BLOW_CMD=1/2` 手动触发一次反吹。

### 5.2 手动触发反吹

写对应 `BLOW_CMD`：

| 值 | 行为 |
----|------|
| 0 | 无操作 |
| 1 | 触发一次反吹 |
| 2 | 触发反吹并重置共享周期 |
| 3 或 0xFFFF | 停止该路反吹 |

`BLOW_CMD=1/2` 启动反吹时，固件会打开对应反吹阀 J2/J5/J8，并同步把对应反吹阀寄存器 40054/40096/40138 置为 1；反吹时长到期或写 3/0xFFFF 停止时，该寄存器会回到 0。

示例：

- S1 手动反吹一次：写 40052=1。
- S2 停止反吹：写 40094=3。
- S3 触发并重置周期：写 40136=2。

### 5.3 直接写反吹阀

也可以直接写反吹阀：

- S1：40054=1。
- S2：40096=1。
- S3：40138=1。

直接写反吹阀与触发反吹命令在同路气路互斥和输出策略上保持一致：都会关闭同路正常抽气阀，并被输出策略视为该路正在反吹。

差异是：直接写反吹阀没有自动倒计时，需要手动写回 0；通过 `BLOW_CMD` 触发的自动反吹会按反吹时长自动结束。自动周期和 `BLOW_CMD` 启动反吹时会检查其它通道，已有通道反吹则跳过本次启动；直接写多个反吹阀寄存器时，代码只保证同路互锁，不做跨通道手动互锁。

反吹阀打开前，固件会先锁存该路切阀前最后一次缓存数据。反吹阀关闭后，不会马上把该路切回输出，而是继续保持 `BLOW_RECOVERY_DELAY_S` 的抽气恢复延时，默认 10 s。这段时间正常抽气阀可以恢复打开，但该路 raw/NOx/O2/state/valid 不刷新，P01/P02/P07 会继续优先使用其它已稳定且有效的通道；延时结束后才重新采用该路新数据。

## 6. 手动标定流程

当前固件不自动执行完整标定流程。也就是说，它不会自动打开标定阀、等待标气稳定、再采样。现场应按下面流程手动完成气路切换和稳定等待，然后再触发标定。

### 6.1 标定联锁

打开某路校准阀后，该路进入标定占用：

- 周期反吹不会启动该路。
- 手动反吹命令不会启动该路。
- 正常抽气阀会保持关闭。
- 反吹阀会保持关闭。
- 关闭校准阀后，自动抽气和周期反吹恢复。

### 6.2 S1 NOx 标定示例

1. 确认 S1 使能：写或读 40014=1。
2. 打开 S1 校准阀：写 40055=1。
3. 确认 S1 正常抽气阀和反吹阀已关闭：40053=0，40054=0。
4. 通入标准气，等待 S1 实时读数稳定：读 40015-40018。
5. 写标准点选择：40044=0/1/2。该寄存器为 uint16，可用 06H 写单寄存器。
6. 如果标定点选择值为 1 或 2，先写入对应标准值。标准值为 float，必须用 10H 一次写完整 2 个寄存器，不能用 06H 只写单个字：
   - 选择值 1（P2）NOx 标准值：40036-40037。
   - 选择值 1（P2）O2 标准值：40038-40039。
   - 选择值 2（P3）NOx 标准值：40040-40041。
   - 选择值 2（P3）O2 标准值：40042-40043。
7. 写 40045=0x0001 触发 NOx 标定。该寄存器为 uint16，可用 06H 写单寄存器。
8. 读 40045：
   - 0x000F 表示成功。
   - 0x0005 表示点选择非法或计算失败。
9. 关闭校准阀：写 40055=0。
10. 正常抽气阀会由自动抽气逻辑恢复，也可按需要手动写 40053=1。

### 6.3 S1 O2 标定示例

S1 O2 标定与 NOx 类似：

- O2 点选择：40047。
- O2 标定触发：40046。
- 触发值：0x0001。
- 恢复默认：0x0002。
- 成功回写：0x000F。

### 6.4 S2/S3 标定寄存器

| 功能 | S1 | S2 | S3 |
|------|----|----|----|
| NOx 点选择 | 40044 | 40086 | 40128 |
| NOx 标定触发 | 40045 | 40087 | 40129 |
| O2 标定触发 | 40046 | 40088 | 40130 |
| O2 点选择 | 40047 | 40089 | 40131 |
| 校准阀 | 40055 | 40097 | 40139 |

标定成功会写入片内 Flash。参数页位于 STM32F103RC 最后一页 `0x0803F800-0x08040000`，Keil IROM 需保持 `0x08000000 + 0x3F800` 以避开该页。反吹间隔和时长也随 Flash 参数保存；反吹三等分相位不保存，是固定策略。

## 7. 4-20 mA 输出

固件同时维护两类模拟量输出：

1. 1 号模拟量模块：输出当前策略结果 NOx/O2。
2. 2 号 6 路模拟量模块：输出 S1/S2/S3 各自 NOx/O2。

| 地址 | 说明 |
|------|------|
| 40010 | 当前策略 NOx 4-20 mA 码 |
| 40011 | 当前策略 O2 4-20 mA 码 |
| 40140 | S1 NOx 4-20 mA 码 |
| 40141 | S1 O2 4-20 mA 码 |
| 40142 | S2 NOx 4-20 mA 码 |
| 40143 | S2 O2 4-20 mA 码 |
| 40144 | S3 NOx 4-20 mA 码 |
| 40145 | S3 O2 4-20 mA 码 |

内部码采用 4000 表示 4 mA，20000 表示 20 mA。NOx 满量程默认为 2500 ppm，O2 满量程默认为 25%。

### 7.1 修改 6 路模块地址

修改地址时只接待修改的 6 路模块，不要同时接 2 路模块。把 `AO_MODULE_SLAVE_2_ADDR_CONFIG_ENABLE` 改为 1，确认 `AO_MODULE_SLAVE_2_ADDR_CONFIG_FROM` 是模块当前地址、`AO_MODULE_SLAVE_2_ADDR_CONFIG_TO` 是目标地址，烧录后上电一次。

固件会只发送一次站号修改命令，成功后 `g_ao_addr_config_status=1`，失败或超时为 2，并且不会继续正常输出轮询。成功后给模块断电重启，再把 `AO_MODULE_SLAVE_2_ADDR_CONFIG_ENABLE` 改回 0 重新烧录正常固件。

## 8. 常见问题

### 8.1 传感器使能寄存器为 1，但 JC 没有动作

检查：

- 当前固件是否已包含 `SENSOR_POWER_GPIO_ENABLE=1`。
- JC1/JC2/JC3 是否为高电平有效。
- PC0/PC13/PB9 是否与硬件原理图一致。
- GPIO 是否被其它功能占用。

### 8.2 传感器异常时抽气阀会不会关闭

自动模式下会。自动抽气逻辑要求该路状态字必须为 `0x1FF`，并且未反吹、校准阀关闭。只要传感器未达温、NOx/O2 不稳定、FMI 异常或通信超时，正常抽气阀都会关闭；状态恢复 `0x1FF` 后再按防抖逻辑自动打开。

同路非反吹、非校准时，手动写正常抽气阀为 1 会进入手动抽气覆盖，不再要求 `0x1FF`。但反吹、校准仍是最高优先级，会立即关闭抽气阀并清除手动覆盖。

### 8.3 反吹阀和抽气阀是否会同时打开

当前代码已互斥，不应该同时打开。同路反吹阀打开时，正常抽气阀会被关闭；同路正常抽气阀打开时，反吹阀会被关闭。

### 8.4 标定过程中会不会自动反吹

不会。只要该路校准阀保持打开，该路周期反吹和手动反吹命令都会被禁止。

### 8.5 单通道模式反吹时会不会切换

会尝试切换。如果目标通道反吹或处于恢复保持期，且其它通道有效并已稳定，会临时切到其它通道。如果没有其它有效通道，则 P35=0 或保持目标缓存输出，具体取决于目标通道当时的有效状态和缓存状态。

### 8.6 读 40012 看不到高字节选路

这是当前协议约定。40012 读回只返回模式低字节 0/1/2；实际输出来源请读 40013。
