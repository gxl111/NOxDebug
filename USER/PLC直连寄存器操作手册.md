# PLC 直连寄存器操作手册

本文档用于 **PLC / HMI / SCADA 作为 Modbus RTU 主站，直接控制 NOxDebug** 的现场接线、组态、寄存器读写和调试操作。

这种方式下，PLC 是唯一控制入口。PLC 通过 RS485 / USART1 直接读取和写入 NOxDebug 保持寄存器；不需要把 4-20 mA 信号接入 PLC 作为控制依据。如果现场还安装外部模拟量输出模块，它可以作为显示或记录的附加输出，但 PLC 直连方式的核心操作仍然是 Modbus 寄存器。

## 1. 适用范围

适合以下现场：

- PLC 需要独立读取 NOx/O2、状态字和三路传感器状态。
- PLC 需要写工作模式 P34、阀门、反吹、标定、报警阈值等寄存器。
- 系统需要 PLC 参与联锁、无人值守或长期运行。
- 现场不希望 PC 上位机长期在线控制。

不适合以下现场：

- PLC 只需要接收 4-20 mA 模拟量，不直接读写寄存器。
- 现场主要由 PC 上位机操作、记录和标定。

上述情况请使用 `USER/上位机控制与PLC模拟量接收操作手册.md`。

## 2. 接线方式

```text
PLC / HMI / SCADA（Modbus RTU 主站）
        │ RS485 A/B
        ▼
NOxDebug USART1 / RS485（Modbus RTU 从站，默认站号 1）
        │
        ├─ CAN1 / CAN2 接三路 NOx 传感器
        ├─ J1-J9 接正常抽气、反吹、校准阀
        └─ JC1-JC3 接传感器使能继电器
```

图片预留：在这里贴 PLC 与 NOxDebug 的 RS485 接线照片，标出 PLC A/B、NOxDebug USART1 A/B、屏蔽层、终端电阻和电源地。

接线要求：

1. PLC 的 RS485 A/B 接 NOxDebug 的 USART1 RS485 A/B。
2. 长线或强干扰环境下，按现场规范处理屏蔽层、终端电阻和共地。
3. 通信不通时，优先检查 A/B 是否接反。
4. 同一条 USART1/RS485 总线上不要再接 PC 上位机作为第二个 Modbus 主站。
5. 这种方式不要求 PLC 接收 4-20 mA 信号；PLC 直接读 40001-40145 保持寄存器。

## 3. 通信参数

NOxDebug 默认 Modbus 从站参数如下：

| 参数 | 默认值 |
|------|--------|
| 物理接口 | USART1 / RS485 半双工 |
| 协议 | Modbus RTU 从站 |
| 从站地址 | 1 |
| 波特率 | 115200 bps |
| 数据位 | 8 |
| 校验 | None |
| 停止位 | 1 |
| 常用功能码 | 03H、06H、10H |

PLC 侧建议配置为：

```text
模式：Modbus RTU 主站
从站地址：1
波特率：115200
数据位：8
校验：None
停止位：1
寄存器字节序：高字节在前
float 字序：高 16 位字在前，低 16 位字在后
```

图片预留：在这里贴 PLC 通信通道配置界面截图，标出站号、波特率、数据位、校验、停止位和轮询周期。

如果现场使用 SD 卡配置通信参数，固件启动时会读取 SD 卡根目录 `config.txt`：

```text
BaudRate=115200
address=1
StopBits=1
```

如果没有 SD 卡或读取失败，使用固件默认值：站号 1、115200、8N1。

## 4. 地址填写规则

本手册使用 **4xxxx 逻辑地址**，从 40001 开始。Modbus RTU 报文中的起始地址是 **0 基 PDU 偏移**。

```text
PDU 起始地址 = 文档地址 - 40001
```

常用地址换算：

| 文档地址 | PDU 偏移十进制 | PDU 偏移十六进制 | 含义 |
|----------|----------------|------------------|------|
| 40001 | 0 | 0x0000 | 当前策略 NOx 高字 |
| 40003 | 2 | 0x0002 | 当前策略 O2 高字 |
| 40005 | 4 | 0x0004 | 当前输出状态字 P07 |
| 40012 | 11 | 0x000B | 工作模式 P34 |
| 40013 | 12 | 0x000C | 当前实际输出来源 P35 |
| 40053 | 52 | 0x0034 | S1 正常抽气阀 |
| 40054 | 53 | 0x0035 | S1 反吹阀 |
| 40055 | 54 | 0x0036 | S1 校准阀 |

PLC 软件常见三种填法：

| PLC 软件要求 | 应填写 |
|--------------|--------|
| 起始地址、Offset、Address | 填 PDU 偏移，例如 40001 填 0 |
| 4x 寄存器号 | 填 40001、40012 这类文档地址 |
| 寄存器序号 | 先按 PLC 手册判断从 0 还是从 1 开始，再用读 40013 验证 |

验证方法：只读 40013 一个寄存器。如果返回值只在 0、1、2、3、4 之间变化，说明站号、地址换算和功能码基本正确。

## 5. 数据类型和功能码

### 5.1 uint16

单个 16 位保持寄存器，高字节在前。状态字、工作模式、阀门、反吹命令、传感器使能都属于 uint16。

示例：状态字 `0x01FF` 在 Modbus 回包中为：

```text
01 FF
```

### 5.2 float

NOx、O2、报警阈值、标定标准值为 IEEE 754 单精度 float，占两个连续保持寄存器。

```text
第 1 个寄存器 = float 高 16 位
第 2 个寄存器 = float 低 16 位
每个寄存器内部 = 高字节在前
```

示例：float `1500.0` 的 32 位值为 `0x44BB8000`，写入时：

| 寄存器 | 值 |
|--------|----|
| 高字寄存器 | 0x44BB |
| 低字寄存器 | 0x8000 |

PLC 常见设置名称可能是：

```text
Register order: High word first
Byte order: High byte first
Float order: ABCD
```

如果 PLC 读出的 NOx/O2 是极大值、极小值或乱跳，优先检查 float 字序。

### 5.3 功能码使用规则

| 功能码 | 用途 | 现场建议 |
|--------|------|----------|
| 03H | 读保持寄存器 | 正常轮询使用 |
| 06H | 写单个保持寄存器 | 只写 uint16，如 P34、阀门、反吹命令 |
| 10H | 写多个保持寄存器 | 写 float 参数，或一次写多个连续 uint16 |
| 01H | 读线圈 | 仅保留兼容，不用于现场阀门控制 |
| 05H | 写单线圈 | 仅保留兼容，不驱动 J1-J9 阀门 |

重要规则：

- 写 float 必须用 10H 一次写完整 2 个寄存器。
- 不要用 06H 单独写 float 的高字或低字。
- 不要从 float 的低字地址开始读写，例如不要单独读写 40002、40004、40007。
- 03H 单次最多读 125 个寄存器；全表 145 个寄存器需要分段。
- 10H 建议每帧不超过 25 个寄存器。

## 6. 第一次通信调试步骤

图片预留：在这里贴 PLC 在线监控或 Modbus 调试画面，标出读 40013、40005、40001-40004 的结果。

按下面顺序调试，不要一开始就把全部点位和写操作加进去：

1. 断电检查 RS485 A/B、屏蔽层、终端电阻和共地。
2. PLC 建立 Modbus RTU 主站通道：115200、8N1、从站地址 1。
3. 用 03H 读 40013，一个寄存器。返回 0、1、2、3 或 4 即通信基本正常。
4. 用 03H 读 40005，一个寄存器。正常输出源常见为 `0x01FF`。
5. 用 03H 读 40001 起 4 个寄存器，确认 P01 NOx 和 P02 O2 的 float 字序。
6. 分别读 40019、40061、40103，确认 S1/S2/S3 三路传感器状态。
7. 确认读数稳定后，再增加 P34、阀门、反吹、标定等写操作。
8. 所有写操作都应做权限保护，避免普通运行周期反复写控制寄存器。

## 7. 最小轮询表

现场首次接入建议只配置下面点位：

| 功能 | 文档地址 | PDU 偏移 | 类型 | 读写 | 说明 |
|------|----------|----------|------|------|------|
| 当前 NOx 输出 P01 | 40001-40002 | 0 | float | 读 | ppm |
| 当前 O2 输出 P02 | 40003-40004 | 2 | float | 读 | % |
| 当前输出状态 P07 | 40005 | 4 | uint16 | 读 | `0x01FF` 表示当前输出源正常 |
| 工作模式 P34 | 40012 | 11 | uint16 | 读/写 | 0 单路、1 主备、2 融合 |
| 实际输出来源 P35 | 40013 | 12 | uint16 | 读 | 0 故障、1 S1、2 S2、3 融合、4 S3 |
| S1 NOx | 40015-40016 | 14 | float | 读 | ppm |
| S1 O2 | 40017-40018 | 16 | float | 读 | % |
| S1 状态 | 40019 | 18 | uint16 | 读 | `0x01FF` 正常 |
| S2 NOx | 40057-40058 | 56 | float | 读 | ppm |
| S2 O2 | 40059-40060 | 58 | float | 读 | % |
| S2 状态 | 40061 | 60 | uint16 | 读 | `0x01FF` 正常 |
| S3 NOx | 40099-40100 | 98 | float | 读 | ppm |
| S3 O2 | 40101-40102 | 100 | float | 读 | % |
| S3 状态 | 40103 | 102 | uint16 | 读 | `0x01FF` 正常 |

推荐分段轮询：

```text
03H 读 40001 起，数量 13：公共输出区
03H 读 40014 起，数量 6：S1 使能、NOx、O2、状态
03H 读 40056 起，数量 6：S2 使能、NOx、O2、状态
03H 读 40098 起，数量 6：S3 使能、NOx、O2、状态
```

## 8. 全量读取建议

如果 HMI 需要完整显示 40001-40145，请优先按功能块分段：

```text
40001 x 13    公共区
40014 x 42    S1 区
40056 x 42    S2 区
40098 x 42    S3 区
40140 x 6     模拟量输出内部码镜像
```

也可以按协议最大长度分两帧：

| 分段 | 文档地址 | PDU 起始地址 | 数量 |
|------|----------|--------------|------|
| 第 1 帧 | 40001-40125 | 0 | 125 |
| 第 2 帧 | 40126-40145 | 125 | 20 |

注意：第二帧从 40126 开始时，40126 是 S3 O2 的低字。HMI 变量仍应按完整 float 定义，不要把低字单独解释成 float。

## 9. 工作模式 P34 操作

工作模式寄存器为 40012，类型 uint16，可用 06H 写。

| 写入值 | 模式 | 含义 |
|--------|------|------|
| 0 | 单路 | 目标 S1 |
| 256 | 单路 | 目标 S2 |
| 512 | 单路 | 目标 S3 |
| 1 | 主备 | S1 为主，默认 |
| 257 | 主备 | S2 为主 |
| 513 | 主备 | S3 为主 |
| 2 | 融合 | 多路有效时取平均 |

写入示例：

```text
06H 写 40012 = 1：主备模式，S1 为主
06H 写 40012 = 257：主备模式，S2 为主
06H 写 40012 = 513：主备模式，S3 为主
06H 写 40012 = 2：融合模式
```

读 40012 只返回低字节模式，即 0、1、2，不返回高字节选路。要判断当前实际输出来自哪里，必须读 40013。

| 40013 值 | 含义 |
|----------|------|
| 0 | 无有效输出源或故障 |
| 1 | S1 |
| 2 | S2 |
| 3 | 融合输出 |
| 4 | S3 |

现场建议：

- 日常运行优先使用主备模式。
- 切换 P34 后，必须读 40013 确认实际输出来源。
- 单路目标反吹或异常时，固件可能临时切到其它有效通道；这不是 PLC 写入失败。

## 10. 状态字判断

状态字出现在：

| 地址 | 含义 |
|------|------|
| 40005 | 当前策略输出状态 P07 |
| 40019 | S1 状态 |
| 40061 | S2 状态 |
| 40103 | S3 状态 |

`0x01FF` 表示该路状态正常且没有通信超时。

| 位 | 值 | 置位含义 |
|----|----|----------|
| bit0 | 0x0001 | O2 FMI 正常 |
| bit1 | 0x0002 | NOx FMI 正常 |
| bit2 | 0x0004 | 加热 FMI 正常 |
| bit3 | 0x0008 | 加热激活 |
| bit4 | 0x0010 | 电源在范围 |
| bit5 | 0x0020 | 传感器达温 |
| bit6 | 0x0040 | O2 信号有效 |
| bit7 | 0x0080 | NOx 信号有效 |
| bit8 | 0x0100 | 固件保留，正常情况下置位 |
| bit9 | 0x0200 | 通信超时或链路丢失 |

常见判断：

| 状态 | 含义 | 处理 |
|------|------|------|
| `0x01FF` | 正常 | 可作为有效输出 |
| `0x0300` | 未收到 CAN 帧或通信超时 | 查传感器电源、CANH/CANL、终端电阻 |
| 非 `0x01FF` 且 bit9=0 | 收到 CAN 帧但条件未满足 | 等待预热或按传感器故障处理 |

PLC 联锁建议：

- `40005 == 0x01FF`：当前输出可信。
- `40013 == 0`：没有可用输出源，应报警或进入保护逻辑。
- 需要分通道报警时，分别判断 40019、40061、40103。

## 11. 传感器使能操作

| 功能 | S1 | S2 | S3 | 类型 | 写入值 |
|------|----|----|----|------|--------|
| 传感器使能 | 40014 | 40056 | 40098 | uint16 | 0 关闭，1 使能 |

当前固件使能后会驱动：

| 通道 | 继电器 | MCU 引脚 |
|------|--------|----------|
| S1 | JC1 | PC0 |
| S2 | JC2 | PC13 |
| S3 | JC3 | PB9 |

操作建议：

- 上电默认三路为 1。
- 关闭某路传感器后，该路会逐渐进入通信超时状态，输出策略会避开该路。
- 传感器电源操作应放在维护或检修权限下，不建议普通轮询周期写入。

## 12. 阀门直接操作

阀门全部通过保持寄存器控制，类型 uint16，可用 06H 写。

| 通道 | 正常抽气阀 | 反吹阀 | 校准阀 |
|------|------------|--------|--------|
| S1 | 40053 / J1 | 40054 / J2 | 40055 / J3 |
| S2 | 40095 / J4 | 40096 / J5 | 40097 / J6 |
| S3 | 40137 / J7 | 40138 / J8 | 40139 / J9 |

写入值：

```text
0 = 关闭
1 = 打开
```

图片预留：在这里贴阀门端子或气路照片，标出 J1-J9 对应正常抽气、反吹、校准。

互锁规则：

- 打开正常抽气阀时，同路反吹阀自动关闭。
- 打开反吹阀时，同路正常抽气阀自动关闭。
- 打开校准阀时，同路正常抽气阀和反吹阀自动关闭。
- 校准阀打开期间，同路正常抽气阀和反吹阀会保持关闭。
- 自动反吹和 BLOW_CMD 启动反吹时，同一时刻只允许一路反吹。
- 如果 PLC 直接手动写多个反吹阀，固件只保证同路互锁，不做跨通道手动互锁；PLC 程序应避免同时打开多路反吹阀。

操作示例：

```text
打开 S1 正常抽气阀：06H 写 40053 = 1
关闭 S1 正常抽气阀：06H 写 40053 = 0
打开 S2 校准阀：    06H 写 40097 = 1
关闭 S2 校准阀：    06H 写 40097 = 0
打开 S3 反吹阀：    06H 写 40138 = 1
关闭 S3 反吹阀：    06H 写 40138 = 0
```

现场建议：

- 正常生产时让固件自动抽气逻辑控制正常抽气阀。
- PLC 只在调试、检修、手动标定时直接写阀门。
- 写阀门前必须确认现场气路安全、反吹气源安全、排气路径安全。

## 13. 反吹操作

| 功能 | S1 | S2 | S3 | 类型 | 说明 |
|------|----|----|----|------|------|
| 反吹周期 | 40048 | 40090 | 40132 | uint16 | 秒，三路共享；写任意一路会同步 |
| 反吹时长 | 40049 | 40091 | 40133 | uint16 | 秒，各路独立 |
| 反吹状态 | 40050 | 40092 | 40134 | uint16 | 0 空闲，1 反吹中 |
| 反吹倒计时 | 40051 | 40093 | 40135 | uint16 | 秒 |
| 反吹命令 | 40052 | 40094 | 40136 | uint16 | 见下表 |

反吹命令：

| 写入值 | 行为 |
|--------|------|
| 0 | 无操作 |
| 1 | 触发一次反吹 |
| 2 | 触发一次反吹，并重置共享周期计时 |
| 3 | 停止该路反吹 |
| 0xFFFF | 停止该路反吹 |

默认值：

```text
反吹周期：3600 s
反吹时长：60 s
反吹后恢复延时：10 s
```

示例：

```text
设置共享反吹周期为 1800 s：06H 写 40048 = 1800
设置 S1 反吹时长为 45 s：  06H 写 40049 = 45
触发 S1 反吹一次：         06H 写 40052 = 1
停止 S1 反吹：             06H 写 40052 = 3
```

说明：

- 反吹周期写 0 或 0xFFFF，只停止周期反吹；仍允许 PLC 用 BLOW_CMD=1/2 手动触发。
- 自动周期按三等分错峰：S2 在 1/3 周期，S3 在 2/3 周期，S1 在第一个完整周期。
- 反吹期间以及反吹结束后 10 s 恢复期内，该路不参与输出选择。
- 通过 BLOW_CMD 启动反吹会按反吹时长自动结束。
- 直接写反吹阀为 1 不会自动倒计时，必须手动写回 0。

## 14. 标定操作

标定会写参数并影响测量结果，建议由有权限的 HMI 页面或 PLC 维护画面执行。不要在正常轮询中反复写触发寄存器。

图片预留：在这里贴标定气路或 HMI 标定页面截图，标出标准气入口、校准阀、点选择和执行按钮。

### 14.1 标定前确认

1. 目标传感器已上电并预热稳定。
2. 现场已经切换到标准气，且浓度稳定。
3. 目标通道不在反吹中。
4. 校准阀打开后，正常抽气阀和反吹阀会自动关闭。
5. 标定标准值为 float，必须用 10H 一次写完整 2 个寄存器。

### 14.2 标定寄存器

| 功能 | S1 | S2 | S3 | 类型 |
|------|----|----|----|------|
| NOx 点 2 标准值 | 40036-40037 | 40078-40079 | 40120-40121 | float |
| O2 点 2 标准值 | 40038-40039 | 40080-40081 | 40122-40123 | float |
| NOx 点 3 标准值 | 40040-40041 | 40082-40083 | 40124-40125 | float |
| O2 点 3 标准值 | 40042-40043 | 40084-40085 | 40126-40127 | float |
| NOx 点选择 | 40044 | 40086 | 40128 | uint16 |
| NOx 标定触发 | 40045 | 40087 | 40129 | uint16 |
| O2 标定触发 | 40046 | 40088 | 40130 | uint16 |
| O2 点选择 | 40047 | 40089 | 40131 | uint16 |
| 校准阀 | 40055 | 40097 | 40139 | uint16 |

点选择：

| 点选择值 | 含义 |
|----------|------|
| 0 | 零点或默认点 |
| 1 | 点 2 |
| 2 | 点 3 |

触发值：

| 写入值 | 含义 |
|--------|------|
| 1 | 执行标定 |
| 2 | 恢复默认标定参数 |

触发寄存器读回：

| 读回值 | 含义 |
|--------|------|
| 0x000F | 标定成功 |
| 0x0005 | 点选择非法或计算失败 |
| 0x0010 | 恢复默认成功 |

### 14.3 S1 NOx 标定示例

```text
1. 写 40055 = 1，打开 S1 校准阀。
2. 通入标准气，等待 40015-40016 的 NOx 读数稳定。
3. 如需点 2 标定，用 10H 写 40036-40037 为点 2 标准 NOx 值。
4. 写 40044 = 1，选择 NOx 点 2。
5. 写 40045 = 1，触发 NOx 标定。
6. 读 40045，确认返回 0x000F。
7. 写 40055 = 0，关闭 S1 校准阀。
8. 恢复正常气路，确认 40053 正常抽气状态。
```

S2/S3 按上表替换地址。

## 15. 报警阈值操作

| 功能 | 地址 | 类型 | 写法 |
|------|------|------|------|
| NOx 高报警阈值 P12 | 40006-40007 | float | 10H 写 2 个寄存器 |
| O2 低报警阈值 P13 | 40008-40009 | float | 10H 写 2 个寄存器 |

写入后必须读回核对。若读回值异常，优先检查 float 字序。

## 16. 不需要接入 PLC 的 4-20 mA 信号

PLC 直连控制方式下，PLC 已经通过 Modbus 直接获得 NOx/O2、状态、来源和各路传感器数据，因此不需要再把 4-20 mA 信号接入 PLC 作为主要测量值。

如果现场仍安装外部模拟量模块，40010、40011、40140-40145 是内部码镜像，可用于诊断：

| 地址 | 含义 |
|------|------|
| 40010 | 当前策略 NOx 的模拟量内部码 |
| 40011 | 当前策略 O2 的模拟量内部码 |
| 40140-40145 | S1/S2/S3 NOx/O2 的 6 路内部码 |

默认内部码：4000 表示 4 mA，20000 表示 20 mA。PLC 直连方式下通常只读这些值用于显示或诊断，不建议写入，因为运行任务会周期性刷新。

## 17. 常见问题

### 17.1 PLC 通信超时

按顺序检查：

1. PLC 是否配置为 Modbus RTU 主站。
2. 从站地址是否为 1，或与 SD 卡 `address` 一致。
3. 波特率是否为 115200，或与 SD 卡 `BaudRate` 一致。
4. 校验是否 None，停止位是否 1。
5. PLC 地址填写的是 40001 还是 0，是否符合 PLC 软件规则。
6. RS485 A/B 是否接反。
7. 现场是否接入了 PC 上位机或其它主站。

### 17.2 能通信但 float 数值不对

读默认报警阈值验证字序：

```text
40006-40007：NOx 高报警阈值，默认约 2000.0
40008-40009：O2 低报警阈值，默认约 15.0
```

如果这两个值明显不对，调整 PLC 的字节序或字序为高字在前。

### 17.3 写 40012 后模式不符合预期

读 40012 只返回 0、1、2，不显示高字节选路。请读 40013 判断实际输出来源。目标通道异常、反吹或恢复期时，固件可能临时切到其它有效通道。

### 17.4 写阀门后又被自动关闭

可能原因：

- 同路校准阀打开时，正常抽气阀和反吹阀会被强制关闭。
- 同路反吹中，正常抽气阀会被强制关闭。
- 传感器状态不是 `0x01FF`，自动抽气不会打开正常抽气阀。
- PLC 程序后续又写了相反的寄存器值。

### 17.5 三路状态出现 0x0300

表示该路尚未收到 CAN 帧或超过 2000 ms 未收到 CAN 帧。检查传感器供电、CAN 接线、终端电阻、传感器启动状态和源地址配置。

## 18. 现场操作原则

- 正常运行时只轮询必要数据，不要周期性写阀门、标定触发、工作模式。
- 写操作要做权限保护，尤其是阀门、校准、反吹、传感器使能和标定。
- 写 float 后立即读回核对。
- 阀门调试一次只操作一路。
- PLC 和 PC 上位机不要同时作为主站接入同一条 USART1/RS485。
- 需要长期由 PC 上位机操作时，应切换到 `USER/上位机控制与PLC模拟量接收操作手册.md` 所述方式。
