# 上位机控制与 PLC 模拟量接收操作手册

本文档用于 **PC 上位机作为 Modbus RTU 主站控制 NOxDebug，PLC 只接收 4-20 mA 模拟量输入** 的现场系统接线、PLC 模拟量配置、联调检查和边界说明。

上位机软件本身的安装、首次连接、页面操作、控制、标定、数据保存和故障排查，以 NOxUpperTool 项目中的 `docs\现场使用说明.md` 为准。本文档不重复上位机按钮和页面细节，只说明它在本系统接法中的位置，以及 PLC 侧应如何接收模拟量。

## 1. 适用范围

适合以下现场：

- PC 上运行 NOxUpperTool，由上位机负责查看数据、控制阀门、触发反吹、执行标定和保存数据。
- PLC 只需要 NOx/O2 的 4-20 mA 模拟量值参与显示、记录、报警或控制。
- PLC 不直接写 NOxDebug 的 P34、阀门、反吹、标定等保持寄存器。
- 现场需要把“上位机控制”和“PLC 模拟量接收”职责分开，避免 PLC 和 PC 同时写同一条 RS485 总线。

不适合以下现场：

- PLC 需要独立读写 40001-40145 保持寄存器。
- PLC 需要直接控制 P34、阀门、反吹或标定。
- 现场不允许 PC 长期作为控制入口。

上述情况请使用 `USER/PLC直连寄存器操作手册.md`。

## 2. 系统接线总图

```text
PC / NOxUpperTool（Modbus RTU 主站）
        │ USB-RS485
        ▼
NOxDebug USART1 / RS485（Modbus RTU 从站，默认站号 1）
        │ UART5 / Modbus RTU 主站
        ▼
外部 4-20 mA 输出模块
        │ 4-20 mA
        ▼
PLC 模拟量输入模块
```

图片预留：在这里贴 **系统接线总图**。图中应标出 PC、USB-RS485、NOxDebug USART1、NOxDebug UART5、外部 4-20 mA 输出模块、PLC 模拟量输入模块、电源、屏蔽层、接地和每一路信号流向。

关键原则：

1. PC 上位机接 NOxDebug 的 USART1 / RS485。
2. NOxDebug 的 UART5 接外部 4-20 mA 输出模块。
3. 外部 4-20 mA 输出模块接 PLC 模拟量输入。
4. PLC 不接 NOxDebug 的 USART1 / RS485 做 Modbus 主站。
5. 同一条 USART1 / RS485 上不要同时存在 PC 和 PLC 两个 Modbus 主站。

## 3. 现场接线

### 3.1 PC 到 NOxDebug

1. 将 USB-RS485 转换器插入 PC。
2. 在 Windows 设备管理器中确认出现 COM 口。
3. 将 USB-RS485 的 A/B 线接到 NOxDebug 的 USART1 RS485 接口。
4. 长线或强干扰环境下，按现场规范处理屏蔽层、终端电阻和共地。
5. 通信一直超时时，优先互换 A/B 线再测试。

图片预留：在这里贴 **PC 到 NOxDebug 通信接线图或照片**，标出 PC COM 口、USB-RS485、A/B 线和 NOxDebug USART1 端子。

NOxDebug 默认通信参数：

| 参数 | 默认值 |
|------|--------|
| 接口 | USART1 / RS485 |
| 协议 | Modbus RTU 从站 |
| 从站地址 | 1 |
| 波特率 | 115200 bps |
| 数据位 | 8 |
| 校验 | None |
| 停止位 | 1 |

### 3.2 NOxDebug 到 4-20 mA 输出模块

NOxDebug 通过 UART5 写外部模拟量输出模块。现场通常有两类输出：

| 模块 | 输出内容 | 典型用途 |
|------|----------|----------|
| 1 号 2 路模块 | 当前策略 NOx、当前策略 O2 | PLC 只需要系统最终输出值时使用 |
| 2 号 6 路模块 | S1 NOx、S1 O2、S2 NOx、S2 O2、S3 NOx、S3 O2 | PLC 需要分别看到三路传感器时使用 |

图片预留：在这里贴 **NOxDebug 到外部 4-20 mA 输出模块接线图或照片**，标出 NOxDebug UART5、模块电源、通信 A/B 和每路模拟量输出端子。

### 3.3 4-20 mA 输出模块到 PLC

1. 将外部模拟量输出模块的电流输出端接入 PLC 模拟量输入模块。
2. PLC 模拟量通道配置为 4-20 mA 电流输入。
3. 按现场端子定义确认二线制、四线制、公共端和隔离要求。
4. PLC 只处理模拟量输入值，不通过 Modbus 控制 NOxDebug。

图片预留：在这里贴 **4-20 mA 模块到 PLC 模拟量输入接线图或柜内端子照片**，标出每一路 4-20 mA 对应的 PLC AI 通道。

## 4. PLC 模拟量通道配置

PLC 侧不需要配置 NOxDebug Modbus 寄存器，只需要配置模拟量输入通道。

推荐通道分配：

| PLC 输入 | 信号来源 | 工程量 |
|----------|----------|--------|
| AI1 | 当前策略 NOx | ppm |
| AI2 | 当前策略 O2 | % |
| AI3 | S1 NOx，可选 | ppm |
| AI4 | S1 O2，可选 | % |
| AI5 | S2 NOx，可选 | ppm |
| AI6 | S2 O2，可选 | % |
| AI7 | S3 NOx，可选 | ppm |
| AI8 | S3 O2，可选 | % |

如果只使用 1 号 2 路模块，PLC 通常只接 AI1、AI2。如果使用 2 号 6 路模块，再按现场需要接入三路独立值。

默认量程换算：

```text
NOx：4 mA = 0 ppm，20 mA = 2500 ppm
O2： 4 mA = 0 %，  20 mA = 25 %
```

PLC 工程量计算：

```text
NOx(ppm) = (电流mA - 4) / 16 * 2500
O2(%)    = (电流mA - 4) / 16 * 25
```

常用检查点：

| 电流 | NOx 对应值 | O2 对应值 |
|------|------------|-----------|
| 4 mA | 0 ppm | 0 % |
| 12 mA | 1250 ppm | 12.5 % |
| 20 mA | 2500 ppm | 25 % |

## 6. 联调步骤

图片预留：在这里贴 **联调记录表或 HMI 对比画面**，标出上位机 P01/P02 与 PLC 模拟量显示值的对比。

联调建议按下面顺序执行：

1. 断电检查 PC、USB-RS485、NOxDebug、外部 4-20 mA 模块、PLC AI 模块接线。
2. 给 NOxDebug、模拟量模块和 PLC 上电。
3. 按 NOxUpperTool `docs\现场使用说明.md` 连接 NOxDebug。
4. 在 NOxUpperTool 实时监控页面确认 P01、P02、P07、P35 正常。
5. 在 PLC HMI 上查看当前 NOx/O2 模拟量工程值。
6. 比较 PLC 显示值与 NOxUpperTool 的 P01/P02，确认量程换算正确。
7. 如使用三路独立模拟量，分别比较 S1/S2/S3 与 PLC 对应 AI 通道。
8. 执行一次安全的状态观察或允许范围内的模式切换，确认 PLC 只接收模拟量，不写 NOxDebug 寄存器。
9. 如需保存数据，按 NOxUpperTool `docs\现场使用说明.md` 开启数据保存。

## 7. PLC 侧日常检查

PLC 只看模拟量输入。建议 HMI 上显示以下内容：

| 显示项 | 来源 | 说明 |
|--------|------|------|
| 当前 NOx | 4-20 mA AI 通道 | 工程量 ppm |
| 当前 O2 | 4-20 mA AI 通道 | 工程量 % |
| S1/S2/S3 独立值 | 可选 6 路模块 | 需要分通道显示时使用 |
| 模拟量断线报警 | PLC AI 模块诊断 | 电流低于合理范围时报警 |
| 上位机在线确认 | 人工或独立信号 | 避免误以为 PLC 正在控制 NOxDebug |

建议报警：

- 模拟量小于 3.6 mA：按断线或模块异常处理。
- 模拟量大于 21 mA：按超量程或模块异常处理。
- NOx/O2 工程量超出现场合理范围：报警并检查 NOxUpperTool 实时值。

## 8. 常见问题

### 8.1 PLC 模拟量没有变化

检查：

- 外部 4-20 mA 模块是否上电。
- NOxDebug UART5 到模拟量模块通信是否正常。
- 模拟量模块输出端是否接到正确 PLC AI 通道。
- PLC AI 通道是否配置为 4-20 mA，不是 0-10 V。
- PLC 量程是否按 NOx 0-2500 ppm、O2 0-25% 配置。
- NOxUpperTool 实时监控页面的 P01/P02 是否本身没有变化。

### 8.2 PLC 显示值和上位机不一致

检查：

- PLC 量程上下限是否正确。
- PLC 是否做了二次缩放。
- PLC 接的是当前策略输出，还是三路独立输出。
- 模拟量模块通道顺序是否接错。
- 电流回路公共端、隔离和供电方式是否符合模块要求。

### 8.3 NOxUpperTool 连接或页面操作问题

如果是 COM 口、程序打不开、通信超时、按钮操作、标定页面、数据保存或工程调试页面的问题，不在本文档重复排查，请查看 NOxUpperTool 项目 `docs\现场使用说明.md` 的“常见问题”和对应页面章节。

### 8.4 P35 显示故障或无输出

处理：

- 在 NOxUpperTool 中查看三路状态是否全部通信超时。
- 查看是否有通道正在反吹或处于恢复期。
- 查看 P34 是否切到不可用的目标通道。
- 检查传感器供电、CAN 接线和传感器预热状态。

## 9. 收尾操作

1. 如不需要继续记录，按 NOxUpperTool `docs\现场使用说明.md` 关闭自动保存。
2. 确认现场阀门、反吹和校准状态已经恢复到正常运行状态。
3. 断开上位机连接。
4. 复制 `logs` 和 `data` 目录。
5. 记录本次操作时间、人员、工况、是否标定、是否反吹和数据文件名。

## 10. 现场操作原则

- PC 上位机是唯一 Modbus 主站。
- PLC 只接收 4-20 mA 模拟量，不读写 NOxDebug 保持寄存器。
- 阀门、反吹、标定、电源控制都在 NOxUpperTool 中执行，具体步骤以 NOxUpperTool `docs\现场使用说明.md` 为准。
- PLC 模拟量通道只做显示、记录、报警或控制逻辑。
- 如果现场需要 PLC 直接写寄存器，应切换到 `USER/PLC直连寄存器操作手册.md` 所述方式，不能两种方式混用。
