# PLC 端 Modbus RTU 配置指南

本文档面向现场 PLC/HMI/SCADA 配置人员，说明如何通过 RS485 Modbus RTU 连接 NOxDebug 板卡，并给出常用寄存器的 PLC 配置方式、地址换算、数据类型和写入注意事项。

完整寄存器定义以 `USER/MODBUS_REGISTER_MAP.md` 和当前固件源码 `USER/modbus_slave.h` / `USER/modbus_slave.c` 为准。现场调试时建议先按本文的“最小轮询表”跑通通信，再逐步增加控制、标定和反吹配置。

---

## 1. 通信接口参数

### 1.1 物理接口

| 项目 | 配置 |
|------|------|
| 接口 | RS485 半双工 |
| 协议 | Modbus RTU 从站 |
| MCU 串口 | USART1 |
| 板卡默认站号 | 1 |
| 默认波特率 | 115200 bps |
| 数据位 | 8 |
| 校验 | None |
| 停止位 | 1 |
| 支持功能码 | 01H、03H、05H、06H、10H |

现场 PLC 应配置为：

```text
Mode:        Modbus RTU Master
Slave ID:    1
Baud rate:   115200
Data bits:   8
Parity:      None
Stop bits:   1
Byte order:  Big-endian register, float = high word first
```

### 1.2 SD 卡覆盖通信参数

固件启动时会尝试读取 SD 卡根目录 `config.txt`，支持以下键名，大小写敏感：

```text
BaudRate=115200
address=1
StopBits=1
```

说明：

- `BaudRate`：从站波特率，建议使用代码表内值：2400、4800、9600、19200、38400、115200、128000、230400。
- `address`：Modbus 从站地址，建议 1-247。
- `StopBits`：1 或 2。
- 校验位当前固定为 None，代码中没有启用奇偶校验配置。

如果没有 SD 卡或读取失败，使用 `USER/app_config.h` 中的默认值：站号 1、115200、8N1。

## 2. 地址换算规则

本板卡文档使用 **保持寄存器 4xxxx 逻辑地址**，从 **40001** 开始。Modbus RTU 帧内的起始地址是 **0 基 PDU 偏移**：

```text
PDU 起始地址 = 4xxxx 逻辑地址 - 40001
```

示例：

| 文档地址 | PDU 起始地址(十进制) | PDU 起始地址(十六进制) | 说明 |
|----------|----------------------|-------------------------|------|
| 40001 | 0 | 0x0000 | 当前 NOx 输出，高字 |
| 40003 | 2 | 0x0002 | 当前 O2 输出，高字 |
| 40005 | 4 | 0x0004 | 当前输出状态字 |
| 40012 | 11 | 0x000B | 工作模式 |
| 40013 | 12 | 0x000C | 当前实际输出来源 |
| 40053 | 52 | 0x0034 | S1 正常抽气阀 |
| 40145 | 144 | 0x0090 | S3 O2 4-20 mA 镜像 |

不同 PLC 软件的地址填写方式不一样：

- 如果 PLC 指令要求填“Modbus 起始地址/Offset”，填上表的 **PDU 起始地址**，例如读 40001 填 `0` 或 `0x0000`。
- 如果 PLC 软件要求填“4x 寄存器号”，填 **40001、40003** 这类文档地址。
- 如果 PLC 软件要求填“寄存器序号”，有的从 1 开始，有的从 0 开始；请用读 40013 的方式验证。正确时，P35 只会返回 0、1、2、3、4 中的一个值。

## 3. 数据格式

### 3.1 uint16

单个 16 位寄存器，高字节在前。

示例：状态字 `0x01FF` 在 Modbus 回包中为：

```text
01 FF
```

### 3.2 float

浮点数为 IEEE 754 单精度，占两个连续保持寄存器，顺序为：

```text
第 1 个寄存器 = float 高 16 位
第 2 个寄存器 = float 低 16 位
每个寄存器内部仍为高字节在前
```

示例：float `1500.0` 的 32 位值为 `0x44BB8000`，写入寄存器时：

| 寄存器 | 值 |
|--------|----|
| 高字寄存器 | `0x44BB` |
| 低字寄存器 | `0x8000` |

PLC 中常见字节/字序设置：

```text
Register order: High word first / Big-endian word
Byte order:     High byte first inside each register
Float order:    ABCD
```

如果 PLC 读出来的数值明显不对，优先检查 float 字序。读 40006-40007，默认 NOx 高报警阈值应接近 2000.0；读 40008-40009，默认 O2 低报警阈值应接近 15.0。

### 3.3 float 写入规则

现场强烈建议：

- 写 float 参数时，使用 **10H 写多个保持寄存器**，一次写完整的 2 个寄存器。
- 不要用 **06H** 写 float 的单个高字或低字。
- 不要从 float 的低字地址开始读写，例如不要单独读写 40002、40004、40007 这类低字地址。

原因：当前固件对 float 按“两寄存器整体”处理，单独写 float 的一个寄存器容易造成参数异常。uint16 类型寄存器可以用 06H 单独写。

## 4. 功能码使用建议

| 功能码 | 用途 | 现场建议 |
|--------|------|----------|
| 03H | 读保持寄存器 | 主要轮询方式 |
| 06H | 写单个保持寄存器 | 只用于 uint16 参数，如 40012、阀门、反吹命令 |
| 10H | 写多个保持寄存器 | 用于 float 参数，或连续写多个 uint16 |
| 01H | 读线圈 | 仅保留兼容，不用于 J1-J9 阀门 |
| 05H | 写单线圈 | 仅保留兼容，不驱动 J1-J9 阀门 |

限制：

- 03H 单次最多读 125 个寄存器。
- 本机保持寄存器总范围 40001-40145，共 145 个寄存器，全表读取需要分两帧。
- 10H 写入时建议每帧不超过 25 个寄存器；写 float 参数建议每次只写一个 float，即 2 个寄存器。
- 阀门控制请写保持寄存器 40053-40055、40095-40097、40137-40139，不要使用线圈。

## 5. 最小轮询表

现场首次接入 PLC 时，建议只配置下面这些点位。

| 功能 | 文档地址 | PDU 偏移 | 类型 | R/W | PLC 说明 |
|------|----------|----------|------|-----|----------|
| 当前 NOx 输出 | 40001-40002 | 0 | float | R | ppm |
| 当前 O2 输出 | 40003-40004 | 2 | float | R | % |

| 工作模式 | 40012 | 11 | uint16 | R/W | 0 单路、1 主备、2 融合 |
| 实际输出来源 | 40013 | 12 | uint16 | R | 0 故障、1 S1、2 S2、3 融合、4 S3 |
| S1 NOx | 40015-40016 | 14 | float | R | ppm |
| S1 O2 | 40017-40018 | 16 | float | R | % |
| S1 状态 | 40019 | 18 | uint16 | R | `0x01FF` 正常 |
| S2 NOx | 40057-40058 | 56 | float | R | ppm |
| S2 O2 | 40059-40060 | 58 | float | R | % |
| S2 状态 | 40061 | 60 | uint16 | R | `0x01FF` 正常 |
| S3 NOx | 40099-40100 | 98 | float | R | ppm |
| S3 O2 | 40101-40102 | 100 | float | R | % |
| S3 状态 | 40103 | 102 | uint16 | R | `0x01FF` 正常 |

建议轮询方式：

```text

03H 读 40014 起，数量 6：S1 使能、NOx、O2、状态
03H 读 40056 起，数量 6：S2 使能、NOx、O2、状态
03H 读 40098 起，数量 6：S3 使能、NOx、O2、状态
```

## 6. 全量分段读取建议

如果 PLC/HMI 需要读取全部 145 个保持寄存器，请分两帧：

| 分段 | 文档地址 | PDU 起始地址 | 数量 |
|------|----------|--------------|------|
| 第 1 帧 | 40001-40125 | 0 | 125 |
| 第 2 帧 | 40126-40145 | 125 | 20 |

注意：第二帧从 40126 开始时，40126 是 S3 `P3_O2` 的低字。对于 PLC 组态变量，建议仍按完整表定义 float，不要把第二帧的第一个寄存器单独解释成 float。更稳妥的方式是按功能块分段读，避免从 float 的低字开始。

推荐分段：

```text
40001 x 13    公共区
40014 x 42    S1 区
40056 x 42    S2 区
40098 x 42    S3 区
40140 x 6     6 路 4-20 mA 镜像
```

## 7. 工作模式配置

工作模式寄存器为 40012，类型 uint16，可用 06H 写。

| 写入值 | 含义 |
|--------|------|
| 0 | 单路模式，目标 S1/ch0 |
| 256 | 单路模式，目标 S2/ch1 |
| 512 | 单路模式，目标 S3/ch2 |
| 1 | 主备模式，S1/ch0 为主，默认 |
| 257 | 主备模式，S2/ch1 为主 |
| 513 | 主备模式，S3/ch2 为主 |
| 2 | 融合模式，多路有效时取平均 |

读 40012 只返回低字节模式，即 0、1、2，不返回高字节选路。PLC 需要判断当前实际输出来自哪一路时，读取 40013：

| 40013 值 | 含义 |
|----------|------|
| 0 | 无有效输出源/故障 |
| 1 | S1/ch0 |
| 2 | S2/ch1 |
| 3 | 融合输出 |
| 4 | S3/ch2 |

配置示例：

```text
06H 写 PDU 地址 0x000B，值 0x0001：主备模式，S1 为主
06H 写 PDU 地址 0x000B，值 0x0101：主备模式，S2 为主
06H 写 PDU 地址 0x000B，值 0x0201：主备模式，S3 为主
06H 写 PDU 地址 0x000B，值 0x0002：融合模式
```

## 8. 状态字说明

状态字出现在：

- 40005：当前策略输出状态。
- 40019：S1 状态。
- 40061：S2 状态。
- 40103：S3 状态。

`0x01FF` 表示该路传感器状态全部正常且未通信超时。

| 位 | 值 | 置位含义 |
|----|----|----------|
| bit0 | 0x0001 | O2 FMI 正常 |
| bit1 | 0x0002 | NOx FMI 正常 |
| bit2 | 0x0004 | 加热 FMI 正常 |
| bit3 | 0x0008 | 加热激活 |
| bit4 | 0x0010 | 电源在范围 |
| bit5 | 0x0020 | 传感器达温 |
| bit6 | 0x0040 | O2 信号有效 |
| bit7 | 0x0080 | NOx 信号有效 |
| bit8 | 0x0100 | 固件保留，正常情况下置位 |
| bit9 | 0x0200 | 通信超时/链路丢失 |

常见值：

| 状态字 | 含义 |
|--------|------|
| `0x01FF` | 正常 |
| `0x0300` | 尚未收到该路 CAN 帧，或超过 2000 ms 未收到该路 CAN 帧 |
| 非 `0x01FF` 且 bit9=0 | 收到 CAN 帧，但传感器条件未全部满足 |

PLC 联锁建议：

- 把 `40005 == 0x01FF` 作为“当前输出可信”的主要判断。
- 把 `40013 == 0` 作为“没有可用输出源”的报警条件。
- 如果需要分别判断各传感器，则监控 40019、40061、40103。

## 9. 传感器使能寄存器

| 功能 | S1 | S2 | S3 | 类型 | 写入值 |
|------|----|----|----|------|--------|
| 传感器使能 | 40014 | 40056 | 40098 | uint16 | 0 关闭，1 使能 |

当前固件 `SENSOR_POWER_GPIO_ENABLE=1`，写 1 会驱动对应 JC1/JC2/JC3 输出高电平：

- S1：40014 -> JC1 / PC0。
- S2：40056 -> JC2 / PC13。
- S3：40098 -> JC3 / PB9。

上电默认三路均为 1。

## 10. 阀门控制寄存器

阀门全部通过保持寄存器控制，类型 uint16，可用 06H 写。

| 传感器 | 正常抽气阀 | 反吹阀 | 校准阀 |
|--------|------------|--------|--------|
| S1 | 40053 / J1 | 40054 / J2 | 40055 / J3 |
| S2 | 40095 / J4 | 40096 / J5 | 40097 / J6 |
| S3 | 40137 / J7 | 40138 / J8 | 40139 / J9 |

写入值：

```text
0 = 关闭
1 = 打开
```

互锁规则：

- 打开正常抽气阀时，同路反吹阀自动关闭。
- 打开反吹阀时，同路正常抽气阀自动关闭。
- 打开校准阀时，同路正常抽气阀和反吹阀自动关闭。
- 校准阀打开期间，同路正常抽气阀和反吹阀会保持关闭。
- 自动反吹和 BLOW_CMD 启动反吹时，同一时刻只允许一路反吹。
- 如果 PLC 直接手动写多个反吹阀，固件只保证同路互锁，不做跨通道手动互锁；现场程序应避免同时打开多路反吹阀。

示例：

```text
打开 S1 正常抽气阀：06H 写 40053 = 1，PDU 地址 0x0034
关闭 S1 正常抽气阀：06H 写 40053 = 0，PDU 地址 0x0034
打开 S2 校准阀：    06H 写 40097 = 1，PDU 地址 0x0060
关闭 S2 校准阀：    06H 写 40097 = 0，PDU 地址 0x0060
```

现场建议：正常运行时由固件自动抽气逻辑控制正常抽气阀；PLC 只在调试、检修、标定时手动写阀门。

## 11. 反吹配置

| 功能 | S1 | S2 | S3 | 类型 | 说明 |
|------|----|----|----|------|------|
| 反吹周期 | 40048 | 40090 | 40132 | uint16 | 秒，三路共享；写任意一路会同步 |
| 反吹时长 | 40049 | 40091 | 40133 | uint16 | 秒，各路独立 |
| 反吹状态 | 40050 | 40092 | 40134 | uint16 | 0 空闲，1 反吹中 |
| 反吹倒计时 | 40051 | 40093 | 40135 | uint16 | 秒 |
| 反吹命令 | 40052 | 40094 | 40136 | uint16 | 见下表 |

反吹命令：

| 写入值 | 行为 |
|--------|------|
| 0 | 无操作 |
| 1 | 手动触发一次反吹 |
| 2 | 手动触发一次反吹，并重置共享周期计时 |
| 3 | 停止该路反吹 |
| 0xFFFF | 停止该路反吹 |

默认值：

```text
反吹周期：3600 s
反吹时长：60 s
反吹后恢复延时：10 s
```

说明：

- 反吹周期写 0 或 0xFFFF，只停止周期反吹；仍允许 PLC 用 BLOW_CMD=1/2 手动触发。
- 自动周期按三等分错峰：S2 在 1/3 周期，S3 在 2/3 周期，S1 在第一个完整周期。
- 反吹期间以及反吹结束后 10 s 恢复期内，该路不参与输出选择。

示例：

```text
设置共享反吹周期为 1800 s：06H 写 40048 = 1800
设置 S1 反吹时长为 45 s：  06H 写 40049 = 45
触发 S1 反吹一次：         06H 写 40052 = 1
停止 S1 反吹：             06H 写 40052 = 3
```

## 12. 标定相关寄存器

现场标定一般由 HMI/上位机完成，PLC 如果需要参与，只建议按工艺顺序发出明确步骤，不要在正常轮询中反复写触发寄存器。

### 12.1 S1 标定寄存器

| 功能 | 地址 | 类型 | 写法 |
|------|------|------|------|
| NOx 点 2 标准值 | 40036-40037 | float | 10H 写 2 寄存器 |
| O2 点 2 标准值 | 40038-40039 | float | 10H 写 2 寄存器 |
| NOx 点 3 标准值 | 40040-40041 | float | 10H 写 2 寄存器 |
| O2 点 3 标准值 | 40042-40043 | float | 10H 写 2 寄存器 |
| NOx 点选择 | 40044 | uint16 | 0、1、2 |
| NOx 标定触发 | 40045 | uint16 | 1 执行，2 恢复默认 |
| O2 标定触发 | 40046 | uint16 | 1 执行，2 恢复默认 |
| O2 点选择 | 40047 | uint16 | 0、1、2 |

S2 对应地址为 40078-40089，S3 对应地址为 40120-40131。

### 12.2 触发结果

| 触发寄存器读回 | 含义 |
|----------------|------|
| `0x000F` | 标定成功 |
| `0x0005` | 点选择非法或计算失败 |
| `0x0010` | 恢复默认成功 |

### 12.3 S1 NOx 标定示例

```text
1. 写 40055 = 1，打开 S1 校准阀。
2. 通入标准气并等待 40015-40016 的 NOx 读数稳定。
3. 如果标定点选择值为 1，先用 10H 写 40036-40037 为 P2 标准 NOx 值。
4. 写 40044 = 1，选择 NOx P2 点。
5. 写 40045 = 1，触发 NOx 标定。
6. 读 40045，确认返回 0x000F。
7. 写 40055 = 0，关闭 S1 校准阀。
```

## 13. 4-20 mA 镜像寄存器

这些寄存器是板卡写外部模拟量模块时的内部码镜像，类型 uint16。

| 地址 | 含义 |
|------|------|
| 40010 | 当前策略输出 NOx 的 4-20 mA 内部码 |
| 40011 | 当前策略输出 O2 的 4-20 mA 内部码 |
| 40140 | S1 NOx 4-20 mA 内部码 |
| 40141 | S1 O2 4-20 mA 内部码 |
| 40142 | S2 NOx 4-20 mA 内部码 |
| 40143 | S2 O2 4-20 mA 内部码 |
| 40144 | S3 NOx 4-20 mA 内部码 |
| 40145 | S3 O2 4-20 mA 内部码 |

默认换算：

```text
4 mA  = 4000
20 mA = 20000
NOx 满量程 = 2500 ppm
O2 满量程  = 25 %
```

一般 PLC 只读这些值用于显示或诊断，不建议 PLC 写这些镜像寄存器，因为运行任务会周期性刷新。

## 14. PLC 调试步骤

1. 断电检查 A/B 线、屏蔽层和终端电阻；确认 PLC 和板卡共地策略符合现场规范。
2. PLC 建立 Modbus RTU Master 通道：115200、8N1、站号 1。
3. 用 03H 读 40013，一个寄存器。能收到 0-4 之间的值，说明站号、波特率、地址换算基本正确。
4. 用 03H 读 40001，数量 4，确认 NOx/O2 float 字序。
5. 用 03H 读 40005，确认状态字。正常输出源应为 `0x01FF`。
6. 分别读 40019、40061、40103，判断三路传感器状态。
7. 如需切换模式，用 06H 写 40012，然后读 40013 确认实际输出来源。
8. 如需调试阀门，先确保现场气路安全，再单独写对应阀门寄存器。
9. 如需写报警阈值或标定标准值，使用 10H 一次写完整 float 的两个寄存器。

## 15. 常见问题

### 15.1 PLC 通信超时

检查：

- PLC 是否为 Modbus RTU Master。
- 站号是否为 1，或与 SD 卡 `address` 一致。
- 波特率是否为 115200，或与 SD 卡 `BaudRate` 一致。
- 校验是否 None，停止位是否 1。
- PLC 地址填写的是 40001 还是 0，需要按软件规则换算。
- RS485 A/B 是否接反。

### 15.2 能通信但 float 数值不对

优先检查 PLC 的字序设置，应为高字在前。可读默认报警阈值验证：

```text
40006-40007：NOx 高报警，默认约 2000.0
40008-40009：O2 低报警，默认约 15.0
```

### 15.3 读 40012 看不到主通道

这是固件协议约定。40012 读回只返回模式低字节 0/1/2。实际输出来源读 40013。

### 15.4 写阀门后又被自动关掉

可能原因：

- 同路校准阀打开时，正常抽气阀和反吹阀会被强制关闭。
- 同路反吹中，正常抽气阀会被强制关闭。
- 未手动覆盖时，传感器状态不是 `0x01FF`，自动抽气不会打开正常抽气阀。

### 15.5 S1/S2/S3 状态是 0x0300

表示该路尚未收到 CAN 帧或超过 2000 ms 未收到 CAN 帧。检查传感器供电、CAN 接线、终端电阻和传感器是否已启动。

---

## 16. 现场建议

- 正常生产只轮询公共输出区和各路状态，不要周期性写阀门、标定触发、工作模式。
- 所有写操作建议做权限保护，尤其是阀门、校准、反吹和传感器使能。
- float 参数写入后应立即读回核对。
- 阀门调试时一次只操作一路，避免 PLC 程序同时打开多路反吹阀。
- 修改 SD 卡 `config.txt` 后需要重新上电，固件启动阶段才会读取配置。
